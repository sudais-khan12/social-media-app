# Social Media App (Messenger Clone)

A real-time, full-stack social media and messaging application built with Next.js and TypeScript. Designed to provide a seamless, Messenger-like chat experience with secure database integration and modern architecture.

## 🚀 Features
* **Real-time Messaging:** Instant chat delivery and updates.
* **Modern UI/UX:** Clean, responsive chat interface tailored for desktop and mobile.
* **Database Integration:** Persistent message history and user data mapping.
* **Type-Safe Architecture:** Fully typed data flow using TypeScript.

## 💻 Tech Stack
* **Framework:** [Next.js](https://nextjs.org/) (App Router)
* **Language:** [TypeScript](https://www.typescriptlang.org/)
* **Database & ORM:** MongoDB / Mongoose (via `models/` & `lib/`)
* **Styling:** Tailwind CSS / PostCSS

## 📂 Project Structure
* `/app` - Next.js App Router pages and layouts.
* `/models` - Database schemas and models.
* `/lib` - Database connection and utility functions.
* `/public` - Static assets and icons.

## 🛠️ Getting Started

First, clone the repository and install the dependencies:

```bash
npm install
# or
yarn install
# or
pnpm install
```
